# סופר סיגריות
PWA מקומי ב-Vanilla JavaScript + HTML + CSS.

כולל רישום timestamp לכל סיגריה, היסטוריה, עלויות, סטטיסטיקות, localStorage, גיבוי/שחזור JSON ו-Service Worker.

## הרצה מקומית
יש להריץ דרך HTTP בגלל ES Modules ו-PWA, לדוגמה: `python -m http.server 8000`.

## פרטיות
אין שרת. הנתונים נשמרים בדפדפן המקומי בלבד.
